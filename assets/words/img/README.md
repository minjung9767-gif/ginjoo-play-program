# 🖼 낱말놀이 동물 사진

낱말놀이 카드에 크게 보여주는 **실사 사진**입니다. 낱말마다 한 장씩, 배경이 없는(투명) PNG.

- 파일 이름은 `js/words.js`의 `img` 경로와 똑같이 맞춰야 합니다
  (예: 원숭이 → `wonsungi.png`).
- **사진이 없거나 못 불러오면 자동으로 이모지(🐒)로 대체**되므로,
  한 장만 바꿔 넣어도 앱은 그대로 동작합니다.
- 크기는 가로·세로 420px 이하로 줄여서 넣습니다(카드에 넉넉한 크기).

## 원본 이미지

`Gemini_Generated_Image_*.png` 는 여러 동물이 한 장에 모여 있는 **원본**입니다.
나중에 다시 자르거나 다른 동물을 추가할 때 쓰려고 남겨 둡니다.
새 원본을 올릴 때도 이 폴더에 그대로 올리면 됩니다(파일 이름 자유).
