## 공용 문구 파일 (선택 — 넣으면 이 부분도 엄마 목소리로)
| 언제 | 파일 이름 | 녹음 내용(예) |
|---|---|---|
| 질문 뒷부분 | `_ask.m4a` | "어디 있어?" |
| 틀렸을 때 | `_retry.m4a` | "어? 다시 찾아볼까?" |
| 칭찬 1 | `_good1.m4a` | "딩동! 잘했어요" |
| 칭찬 2 | `_good2.m4a` | "우와, 잘 찾았어요" |

> 파일 형식은 m4a·mp3 등 무엇이든 괜찮습니다.
> 파일 이름만 위와 똑같이 맞춰서 이 폴더에 넣으면 자동으로 엄마 목소리로 바뀝니다.
