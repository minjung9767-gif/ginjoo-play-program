# 🔢 숫자 놀이 녹음 파일 넣는 곳

숫자 놀이(동물 친구 밥 주기)에서 쓰는 **엄마 목소리 녹음 파일**을 여기에 넣습니다.
파일이 없으면 자동 음성(TTS)으로 대체되므로, 있는 것부터 하나씩 채워도 됩니다.
**가장 먼저 추천: 숫자 3개 + "○개 주세요" 3개 + 칭찬 문구 4개 (10개)**

## ⭐ 꼭 넣으면 좋은 것
| 언제 | 파일 이름 | 녹음 내용 |
|---|---|---|
| 하나 줄 때 | `1.m4a` | "하나!" |
| 둘 줄 때 | `2.m4a` | "둘!" |
| 셋 줄 때 | `3.m4a` | "셋!" |
| 부탁 (1개) | `ask-1.m4a` | "한 개 주세요~" |
| 부탁 (2개) | `ask-2.m4a` | "두 개 주세요~" |
| 부탁 (3개) | `ask-3.m4a` | "세 개 주세요~" |
| 딱 맞게 줬을 때 | `_thanks.m4a` | "냠냠, 고마워!" |
| 덜 주고 가만히 있을 때 | `_more.m4a` | "하나 더 줄래?" |
| 더 줬을 때 | `_ouch.m4a` | "아이고~ 배 아야!" |
| 한 판 끝 | `_finish.m4a` | "다 먹었다! 긴주 최고!" |

> 더 줄 때를 위해 `4.m4a`("넷!"), `5.m4a`("다섯!")도 있으면 좋아요. 나중에 5개까지 늘릴 때는 `ask-4.m4a`("네 개 주세요~"), `ask-5.m4a`("다섯 개 주세요~")가 쓰여요.

## 선택: 동물 소리 · 먹이 이름
| 동물 | 울음 파일 | 내용 | 먹이 파일 | 내용 |
|---|---|---|---|---|
| 강아지 | `cry-gangaji.m4a` | "멍멍!" | `food-ppyeo.m4a` | "뼈다귀" |
| 고양이 | `cry-goyangi.m4a` | "야옹!" | `food-saengseon.m4a` | "생선" |
| 토끼 | `cry-tokki.m4a` | "깡충깡충!" | `food-danggeun.m4a` | "당근" |
| 원숭이 | `cry-wonsungi.m4a` | "우끼끼!" | `food-banana.m4a` | "바나나" |
| 다람쥐 | `cry-daramjwi.m4a` | "쪼르르!" | `food-dotori.m4a` | "도토리" |

> 부탁은 "멍멍!" → "뼈다귀" → "두 개 주세요~" 순서로 이어서 나옵니다.
> 파일 형식은 m4a·mp3 등 무엇이든 괜찮습니다(이름 끝을 `.m4a`로 맞춰 주세요).
> 파일 이름만 위와 똑같이 맞춰서 이 폴더에 넣으면 자동으로 엄마 목소리로 바뀝니다.
