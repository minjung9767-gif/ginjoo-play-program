# 🌱 잭과 콩나무 — 녹음용 안내표 (천천히 읽기)

이 폴더에 **잭과 콩나무** 녹음 파일을 올립니다. (목소리: 엄마 / 아빠 — 정해서 알려주세요)
※ 거인은 무섭지 않게 **코 고는 잠꾸러기 거인**으로 순화했어요.

## 천천히 읽는 법 ⏱️
- 아래 각 장면은 **한 줄씩** 짧게 끊어 두었어요.
- `…` 표시가 나오면 **잠깐 숨 쉬고**, 다음 줄로 넘어가세요.
- 위에서 아래로 **한 줄 한 줄** 읽으면 저절로 천천히, 다정하게 읽혀요.
- **한 장면 = 녹음 파일 하나.** 장면이 끝나면 저장하고, 다음 장면을 새로 녹음하세요.

## 올리는 법
1. 이 `kongnamu` 폴더 화면에서 **Add file → Upload files**
2. 녹음 파일 15개를 아래 파일 이름과 **똑같이** 맞춰서 끌어다 놓기
3. **Commit changes**
4. 다 올리면 알려주세요 — 앱에 연결해 드릴게요. (이름이 다르면 그 이름을 알려주세요)
