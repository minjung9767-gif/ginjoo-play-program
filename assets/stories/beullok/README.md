## 녹음 팁

- **조용한 곳**에서, 폰을 입에서 한 뼘쯤 떨어뜨리고 녹음해 주세요.
- 말하기 **전후로 1초쯤 쉬었다가** 시작/종료 버튼을 누르면 소리가 잘리지 않아요.
- 잠자리 동화니까 **천천히, 조곤조곤**하게. 잘못 읽었으면 그 장면만 다시 녹음하면 돼요.
- 5번(아야!), 8번(안아주는 장면)은 특히 **감정을 살려서** 읽어 주시면 좋아요.
- 파일 형식은 `.m4a`가 기본이에요 (아이폰 음성 메모, 갤럭시 녹음기 모두 `.m4a`).

## 올리는 법

1. 이 `beullok` 폴더 화면에서 **Add file → Upload files**
2. 녹음 파일 13개를 위 이름과 똑같이 맞춰서 끌어다 놓기
3. **Commit changes**

파일을 올린 뒤 알려주시면, 앱에 잘 연결됐는지 확인하고 반영할게요.
파일 이름이 위와 다르면 그 이름을 알려주세요 — 코드 쪽 경로를 맞춰 드릴게요.

**아직 파일을 안 올려도 앱은 정상 동작해요.** 녹음이 없는 장면은 자동 음성(로봇 목소리)으로 읽어 주고, 파일을 올리면 그때부터 엄마 목소리로 바뀝니다.
